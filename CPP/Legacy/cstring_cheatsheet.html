길이 / 비교

코드설명태그
cs.GetLength()문자 수 반환 (바이트 아님)
cs.IsEmpty()비어있으면 TRUE
cs == _T("abc")동등 비교 (연산자 오버로딩)
cs.Compare(_T("abc"))대소문자 구분 비교, 음수/0/양수
cs.CompareNoCase(_T("abc"))대소문자 무시 비교std엔 없음
💡 CompareNoCase는 std::string에 없는 CString 전용 기능. std에서 구현하려면 transform + compare 조합이 필요해서 CString이 편한 부분

검색 (Find)

코드설명태그
cs.Find(_T("ab"))첫 등장 위치, 없으면 -1-1 체크!
cs.Find(_T("ab"), 3)인덱스 3부터 탐색
cs.Find(TCHAR('a'))문자 탐색
cs.ReverseFind(TCHAR('a'))뒤에서부터 문자 탐색
cs.FindOneOf(_T("aeiou"))문자셋 중 첫 등장
⚠️ CString의 Find는 못 찾으면 -1 반환 (std::string의 npos와 다름!). int pos로 받고 if (pos != -1)로 체크

CString ↔ std::string 변환

방향코드설명
CString → stdstd::string ss(CT2CA(cs));유니코드 환경 (권장)
CString → stdstd::string ss(cs);MBCS 환경만 가능
CString → stdstd::wstring ws(cs);유니코드 빌드, wstring으로
std → CStringCString cs(ss.c_str());MBCS 환경
std → CStringCString cs(CA2CT(ss.c_str()));유니코드 환경 (권장)
⚠️ 유니코드 빌드 (대부분의 현대 MFC)에서는 CT2CA / CA2CT 매크로 사용. <atlconv.h> 포함 필요. 그냥 캐스팅하면 데이터 손실 위험

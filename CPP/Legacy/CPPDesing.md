## * 그리고 &, 어디에 붙일 것인가?
- 문법적으로 *와 &는 선언자에 붙이는 것이 맞다
    
    ```cpp
    int *a; // 왜냐하면 *a를 썼을 때 int 값을 얻을 수 있으므로
    ```

- 그럼에도 `int* a;` 같은 것을 하는 이유는 가독성 때문
    - 하지만 `int* a, b;` 같은 상황에서 매우 치명적임 
        ```cpp
        int *a;
        int b;
        // 와 같은 상황이다
        ```
    - 그래서 내 생각에는 `int *a`와 같이 선언자에 붙이는 것이 훨씬 좋은 것 같다

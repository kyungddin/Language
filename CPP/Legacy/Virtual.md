# Virtual Review
가상 함수 관련 개념들 Review


# Down Casting & Up Casting
- Down Casting: 자식포인터로 부모 객체 가리키기 (쓰지 말자..)
- Up Casting: 부모 포인터로 자식 객체 가리키기 (자식 -> 부모로 형 변환)


# 함수 재정의
- 부모의 멤버 함수를 자식에서 새로 정의하는 것
- 정적 바인딩 발생
- 컴파일 시간 다형성


# 가상 함수(Virtual Function)
- virtual 키워드의 순수 목적: 자신에 대한 호출 바인딩을 런타임으로 미룸
- 런타임 다형성
- 가상 함수의 목적은 자신의 목적에 맞게 자식이 함수를 재정의하도록 하는 지침
    - 즉 인터페이스!
- 자식부터는 이러한 virtual을 생략 가능하다!


# 동적 바인딩
- 동적 바인딩은 기본 클래스 포인터로 가상 함수 호출 시 발생!
    - 이때 포인터는 파생 클래스 객체를 가리킴


# C++11: override & final 키워드
- override: 컴파일러에게 오버라이딩을 확인하도록 지시
    - 파생 클래스의 가상 함수 원형 뒤에 작성
- final
    - 1. 가상 함수 원형 뒤에 작성하면 오버라이딩 금지!
    - 2. 클래스 뒤에 작성하면 상속 금지!


# 가상 소멸자 (매우 중요)
- 원래는 파생 클래스 소멸자 - 기본 클래스 소멸자 순으로 실행되어야 건강함
- 근데 기본 클래스 포인터로 자식 객체를 delete()하면.. 자식 소멸자 실행 불가
- 이를 막기 위해 기본저긍로 기본 클래스의 소멸자는 virtual로 작성해주자!


# 순수 가상 함수 & 추상 클래스
- 순수 가상 함수: 선언만이 존재하는 가상 함수
    - =0; 을 통해 명시
- 추상 클래스: 하나 이상의 순수 가상 함수를 가진 클래스
    - 객체 생성 불가!


# Virtual Review (Upcasting 관점에서)
- 업캐스팅이 빛나는 구체적 예시
```cpp
void makeSound(Animal* a) 
{
    a->speak();
}

makeSound(new Dog());
makeSoung(new Cat()); // 이렇게 하나의 함수로 전부 처리 가능
```

- virtual은 동적 바인딩이다!
    - 컴파일 타임에서는 vtable 생성
    - 런타임에서는 vptr이 객체 타입에 맞는 vtable을 가리킴
        - 각 클래스 별 vtable이 존재하는데 vptr이 적절한 클래스를 선택함
